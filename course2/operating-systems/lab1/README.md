# Операционные системы, лабораторная работа 1

Процессы и неименованные каналы (pipe) в Windows. Вариант 11 (группа вариантов 3).

## Задание

Родительский процесс создаёт два дочерних процесса; все три - разные программы.
Родительский процесс принимает от пользователя строки произвольной длины и пересылает их в pipe1.
child1 переводит строки в верхний регистр, child2 превращает все пробельные символы в символ `_`.
child2 пересылает результат родительскому процессу, родительский процесс выводит его в стандартный
поток вывода. child1 и child2 соединены дополнительным каналом. Системные ошибки нужно обрабатывать.

```
пользователь -> parent --pipe1--> child1 --pipe_mid--> child2 --pipe2--> parent -> экран
```

| Файл | Что делает |
|---|---|
| `parent.c` | создаёт три канала (`CreatePipe`) и двух детей (`CreateProcess`) с перенаправленными stdin/stdout; читает строки, отправляет в pipe1, печатает ответ из pipe2; в конце закрывает каналы и ждёт детей (`WaitForSingleObject`, `GetExitCodeProcess`) |
| `child1.c` | читает свой stdin (pipe1), латинские буквы -> заглавные, пишет в свой stdout (pipe_mid) |
| `child2.c` | читает свой stdin (pipe_mid), пробельные символы кроме `\n` -> `_`, пишет в свой stdout (pipe2) |

## Сборка и запуск

Нужны Windows, [zig](https://ziglang.org/download/) (или gcc из MinGW) и Git Bash / MSYS2 с `make`.

```sh
make                  # parent.exe, child1.exe, child2.exe -> build/
make test             # все тесты (tests/tests_*.txt)
make memcheck         # все тесты под Dr. Memory (проверяет и дочерние процессы)
build/parent.exe      # ввод строк с клавиатуры; конец - Ctrl+Z и Enter
```

Все три программы должны лежать в одной папке: parent ищет детей рядом со своим exe.

## Тесты

Файлы `tests/tests_parent.txt`, `tests/tests_child1.txt`, `tests/tests_child2.txt`; формат описан в начале
`tests_parent.txt`. Кроме строк `input:`/`out:` есть `infile:` (весь ввод из файла) и `outfile:` (весь вывод
сравнивается с файлом) - для пустых строк, пробелов в конце строки и строки в 30000 символов.
Ожидаемые ответы для файлов из `tests/data` посчитаны на Python.

## Замечания по заданию

- **Строки любой длины.** parent читает строку в буфер, который растёт вдвое (`realloc`). Дети строки не
  собирают: читают канал порциями по 4096 байт (`ReadFile`), меняют каждый символ и сразу пишут дальше.
- **Нет взаимной блокировки на длинных строках.** Если записать в pipe1 сразу строку больше, чем вмещают
  каналы, все процессы встанут: parent ждёт места в pipe1 и не читает pipe2, а дети ждут места в своих
  выходных каналах. Поэтому parent отправляет строку порциями по 4096 байт и после каждой порции читает
  ответ на неё. Оба ребёнка заменяют символ ровно одним символом, так что ответ на n байт - ровно n байт.
- **Наследование описателей.** Каналы создаются ненаследуемыми; перед запуском ребёнка наследуемыми
  делаются только два его конца, после запуска флаг снимается. parent закрывает у себя концы, отданные
  детям. Иначе конец ввода не дошёл бы до child2 и программа зависла бы на выходе.
- **Пробельные символы** - те, для которых `isspace()` истинна: пробел, `\t`, `\r`, `\v`, `\f`.
  `\n` не заменяется: это граница строк. Окончания строк Windows (`\r\n`) приходят в parent уже как `\n`
  (стандартный ввод открыт в текстовом режиме), поэтому лишний `_` в конце строки не появляется.
- **Регистр** меняется только у латинских букв (`toupper` в локали "C"); русские буквы в UTF-8 проходят
  без изменений.
- **Ошибки:** неудача любого системного вызова - сообщение `Error: ... (Windows error N)` и код 1;
  нет child1.exe/child2.exe рядом с parent.exe - `Error: can not start ...child1.exe (Windows error 2)`;
  ребёнок завершился раньше времени или с кодом не 0 - тоже сообщение и код 1.

# Тесты медианного фильтра (вариант 11)
#
# Как запустить:  make test                (Git Bash: все тесты)
#                 ..\windows\run_tests.bat (то же из проводника или cmd)
#
# Формат одного теста (тесты разделяются пустой строкой):
#   name:    название теста - просто для понимания
#   args:    аргументы программы через пробел
#   input:   строка стандартного ввода (их может быть несколько)
#   infile:  файл, который подаётся на стандартный ввод целиком
#   out:     строка, которую программа должна вывести в stdout
#   outre:   то же, но шаблоном (регулярное выражение) - для времени и номера процесса
#   outfile: файл, с которым должен совпасть весь вывод программы
#   err:     строка, которую программа должна вывести в stderr (сообщения об ошибках)
#   code:    код возврата: 0 - всё хорошо, 1 - ошибка
# Строки, начинающиеся с #, - комментарии.
# Ожидаемые матрицы и контрольные суммы посчитаны на Python (тот же генератор и тот же фильтр).

#
# Формат одного теста (тесты разделяются пустой строкой):
#   name:  название теста - просто для понимания
#   args:  аргументы программы через пробел; аргумент с пробелом - в кавычках: " 7"
#   input: строка, которую "вводит пользователь" (для задания 10)
#   out:   строка, которую программа должна вывести в stdout (printf)
#   outre: то же, но шаблоном (регулярное выражение) - для случайных чисел
#   err:   строка, которую программа должна вывести в stderr (сообщения об ошибках)
#   code:  код возврата: 0 - всё хорошо, 1 - ошибка
#   file:  какой файл программа должна создать; fout: строки этого файла
# Строки, начинающиеся с #, - комментарии.
#
# Чтобы добавить свой тест - скопируй любой блок и поменяй значения.

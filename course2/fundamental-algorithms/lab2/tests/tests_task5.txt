#                          bash run_tests.sh --memcheck 5   (то же под valgrind)
#
# Формат одного теста (тесты разделяются пустой строкой):
#   name:  название теста - просто для понимания
#   args:  аргументы программы через пробел; аргумент с пробелом - в кавычках: "a b"
#   out:   строка, которую программа должна вывести в stdout (printf)
#   err:   строка, которую программа должна вывести в stderr (сообщения об ошибках)
#   code:  код возврата: 0 - всё хорошо, 1 - ошибка
# Строки, начинающиеся с #, - комментарии.
# Аргументы программы: <флаг> <значение> [основание]  - флаг без %: Ro Zr Cv CV to TO mi mu md mf.
# Программа печатает результат через overfprintf и через oversprintf (одно ядро) и что они вернули.
# Правильные ответы проверены на Python: римские числа, цекендорфово представление (обратным
# переводом), системы счисления, дампы памяти (struct.pack, порядок байт little-endian).
# Стандартные флаги (демонстрация) сверены со стандартной snprintf на 200000 случайных спецификаторов.

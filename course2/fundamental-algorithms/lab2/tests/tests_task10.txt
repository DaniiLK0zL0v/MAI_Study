# Формат одного теста (тесты разделяются пустой строкой):
#   name:  название теста - просто для понимания
#   args:  аргументы программы через пробел; аргумент с пробелом - в кавычках: "a b"
#   out:   строка, которую программа должна вывести в stdout (printf)
#   err:   строка, которую программа должна вывести в stderr (сообщения об ошибках)
#   code:  код возврата: 0 - всё хорошо, 1 - ошибка
# Строки, начинающиеся с #, - комментарии.
# Аргументы программы: <eps> <a> <f0> [f1 ... fn]  ->  f(x) = f0 + f1*x + ... + fn*x^n.

#   g_k = сумма по j >= k:  f_j * C(j, k) * a^(j - k)   (бином Ньютона для ((x - a) + a)^j).
#
